# Role Journeys

## Investor Journey

1. Open cabinet and see access status summary.
2. Discover published deals via safe list and filters.
3. Request access to deal.
4. Track request status and safe reasons.
5. After approval, open gated allowed details.
6. Request intro if eligible.

## Seller Journey

1. Open cabinet and complete seller readiness.
2. Accept marketplace disclaimer.
3. Create listing draft -> submit for review.
4. Track operator review state (approved/returned/rejected).
5. If published, monitor freshness status and renew/confirm when needed.

## Operator Journey

1. Monitor queue counters and SLA.
2. Process access, listing, intro, moderation, and notification queues.
3. Approve/refuse with required reason codes.
4. Trigger follow-up workflows and verify audit traces.

## Moderator Journey

1. Review moderation incidents.
2. Apply low-risk reversible sanctions where permitted.
3. Escalate high-risk actions to admin.

## Admin Journey

1. Review critical warnings and irreversible actions.
2. Manage kill switches and feature flags.
3. Resolve ledger correction/reconciliation escalations.
