# Role QA Checklist

## Public

- [ ] Marketplace list loads and shows only published safe data.
- [ ] Unpublished/rejected listings are not visible.
- [ ] Gated/private details are denied.

## Member / Investor

- [ ] Can view own cabinet safely.
- [ ] Can save and list own filters.
- [ ] Can request marketplace access where eligible.
- [ ] Sees safe status/reason/next action in cabinet.

## Member / Seller

- [ ] Can view own seller readiness and listing status.
- [ ] Can submit eligible listing draft for review.
- [ ] Sees freshness warnings and required actions.
- [ ] Cannot bypass publish/review gates.

## Operator

- [ ] Sees queue counters and SLA.
- [ ] Can approve/refuse access/listing/intro with reason.
- [ ] Can process retries and resolution actions.
- [ ] Can see corresponding audit trail.

## Moderator

- [ ] Can review moderation incidents allowed by policy.
- [ ] Cannot access restricted internals outside moderation scope.

## Admin

- [ ] Can access critical controls and irreversible approvals.
- [ ] Can change feature flags and see audit event.
- [ ] Can access reconciliation warnings and admin actions.
